# LinkBetweenUs (LBU) 产品功能介绍

## 产品概述

LinkBetweenUs（简称 LBU）是一款 **QQ/微信风格** 的即时通讯桌面应用，支持实时私聊、群聊、好友管理、文件分享，并内置了基于 Dify 平台的 **AI 智能助手**。应用采用客户端-服务器架构，提供 Windows 桌面客户端，后端服务支持多设备同时在线。

---

## 核心功能
LinkBetweenUs 的核心功能包括用户注册与登录、好友管理、即时通讯、文件分享以及 AI 智能助手。

### 1. 用户注册与登录

- 用户通过 **账号 + 密码** 注册成为 LBU 用户
- 每个账号全局唯一，注册时会检测账号是否已被占用
- 登录后获得 JWT Token，后续所有操作自动携带此 Token 进行身份验证
- Token 有效期为 **24 小时**
- 支持 **顶号功能**：当同一个账号在新的设备或窗口登录时，旧的登录会自动失效，保护账号安全
- 支持 **修改密码** 和 **重置密码**

### 2. 好友系统

#### 添加好友
- 通过 **账号搜索** 查找其他用户
- 向目标用户发送 **好友请求**，对方会收到实时通知
- 对方可以选择 **接受** 或 **拒绝** 好友请求
- 好友请求状态：待处理(PENDING) → 已接受(ACCEPTED) / 已拒绝(REJECTED)

#### 好友列表
- 显示所有已添加的好友，包含头像（昵称首字符）和昵称
- **实时显示好友在线状态**：绿色圆点表示在线，灰色表示离线
- 点击好友即可开始聊天

#### 删除好友
- 可以从好友列表中删除好友
- 删除后关系状态变为 DISSOLVED（已解除）

### 3. 一对一私聊

- **实时消息收发**：消息通过 WebSocket 实时传输，无需刷新
- **消息状态追踪**：
  - 发送中 → 已送达(SENT) → 已投递(DELIVERED) → 已读(READ)
  - 发送方可以看到消息是否已送达、是否已被阅读
- **离线消息**：如果对方不在线，消息会暂存在服务器，对方上线后自动接收
- **聊天记录**：支持向上滚动加载更多历史消息
- **会话列表**：显示所有私聊会话，按最后一条消息时间排序，显示未读消息数

### 4. 群组聊天

- **创建群组**：任何用户都可以创建群组，自定义群名
- **加入群组**：通过群 ID 搜索并加入已有群组
- **群聊消息**：群内所有成员都可以收发消息，消息实时广播给所有在线成员
- **群组信息**：查看群名称、群成员列表等详细信息

### 5. AI 智能助手 (Dify)

LBU 内置了一个 AI 聊天机器人，通过集成 **Dify 平台** 实现。

#### 如何使用
- 在侧边栏可以看到一个紫色的 **"AI 小助手"** 卡片
- 首次使用时点击 **"添加"** 按钮，AI 助手会立即成为你的好友（无需等待验证）
- 添加后，点击 **"聊天"** 即可与 AI 开始对话

#### AI 能力
- 由 Dify 平台背后的 **大语言模型（LLM）** 驱动，可以进行智能对话
- **支持会话记忆**：AI 会记住最近 30 天内的对话上下文，实现连续对话
- 支持 **DeepSeek-R1** 等推理模型，推理过程会在服务端自动处理
- 回复采用异步生成，不会阻塞你的操作

#### 使用体验
- 发送消息后，聊天窗口会显示 **"AI 正在思考中…"** 的提示
- AI 回复完成后，提示自动消失，显示完整的回复内容
- 如果 AI 服务暂时不可用，会友好地提示 **"AI服务暂时不可用，请稍后再试"**

### 6. 文件分享

- 支持发送 **图片、音频、视频** 以及任意类型的文件
- **单文件大小限制：50MB**
- 图片消息在聊天窗口直接展示缩略图
- 音频和视频文件支持 **内联播放**（点击即可在聊天窗口内播放）
- 其他类型文件提供 **下载链接**

### 7. 在线状态感知

- 好友列表中每个好友旁显示 **在线状态指示灯**：
  - 🟢 绿色 = 在线
  - ⚫ 灰色 = 离线
- 状态更新是 **实时的**：好友上线/下线时，指示灯立即变化
- 支持 **多设备同时在线**：同一个账号可以在多台电脑上同时登录

### 8. 主题切换

- 支持 **亮色模式** 和 **暗色模式**
- 切换即时生效，无需刷新页面
- 暗色模式适合夜间使用，减少眼部疲劳

## 桌面客户端特色

LinkBetweenUs 是一个原生的 **Windows 桌面应用**（基于 Electron），具有以下特色：

- **双窗口设计**：
  - 登录窗口：小巧精致 (430×530)，不可调整大小
  - 主窗口：宽敞实用 (920×680)，登录成功后自动切换
- **退出登录** 时，窗口自动缩小回登录窗口大小
- **界面设计**：简洁清晰，无表情符号，使用文字和首字符头像
- **侧边栏布局**：左侧显示好友列表、群组列表和 AI 助手入口，右侧为聊天区域

## 用户操作流程

### 新用户上手流程
1. 打开 LBU 桌面应用 → 看到登录窗口
2. 点击注册 → 输入账号和密码 → 注册成功
3. 返回登录 → 输入账号密码 → 进入主界面
4. 在搜索框搜索好友账号 → 发送好友请求
5. 等待对方接受 → 开始聊天

### 与 AI 助手聊天
1. 登录后查看侧边栏下方的 AI 助手卡片
2. 点击"添加"按钮（即时通过）
3. 点击"聊天"进入 AI 对话窗口
4. 输入问题 → 稍等片刻 → AI 回复

### 群聊流程
1. 点击群组区域的"+"按钮 → 选择"创建群组"
2. 输入群名称 → 创建成功
3. 将群 ID 分享给好友
4. 好友通过群 ID 搜索并加入
5. 群内发送消息，所有在线成员实时可见

## 常见问题

**Q: 忘记密码怎么办？**
A: 在登录页面点击"忘记密码"，输入账号和新密码即可重置。

**Q: 为什么我登录后之前的设备被踢下线了？**
A: LBU 采用顶号机制，同一账号在新设备登录时，旧设备的登录会自动失效。这是为了保护账号安全。

**Q: AI 助手能做什么？**
A: AI 小助手由大语言模型驱动，可以进行智能对话、回答问题、提供建议等。它拥有 30 天的会话记忆能力。

**Q: AI 助手回复很慢怎么办？**
A: AI 回复需要一定的处理时间，通常在几秒到十几秒之间。如果超过 60 秒未回复，系统会提示 AI 服务暂时不可用。你可以稍后再试。

**Q: 发消息对方不在线会丢失吗？**
A: 不会。消息会保存在服务器上，对方上线后会自动收到离线期间的所有消息。

**Q: 支持多设备同时登录吗？**
A: 支持。同一个账号可以在多台电脑上同时在线，消息会同步到所有设备。

**Q: 可以发送多大的文件？**
A: 单个文件最大 50MB。支持图片、音频、视频及任意格式文件。

**Q: 如何知道对方是否看到了我的消息？**
A: 消息状态会显示：已送达（对方在线时投递成功）和已读（对方已查看）。你可以在聊天窗口中看到消息的状态变化。
