# 生成周报

当用户需要写周报时，按以下步骤执行：

1. 如果用户还没有提供具体内容，先问清楚三件事：本周完成了哪些事情、遇到了什么问题、下周有什么计划。
2. 内容齐备后，整理成一份简洁的周报，包含三个小节：本周完成、遇到的问题、下周计划；每节用几句话概括，只写用户说过的事情，不要编造。
3. 用 write_file 工具把周报保存到工作区的 report-周报.md 文件。
4. 告诉用户文件保存的位置，并把周报内容直接展示给用户。
